# 🎁 Amigo Secreto - Oracle Next Education

📌 Este é um projeto desenvolvido no programa **Oracle Next Education**, que simula um **Amigo Secreto** digital. O objetivo é permitir que os participantes sorteiem nomes de forma automática.

## 🎲 Como Funciona
1. O usuário insere os nomes dos participantes no campo de texto e adiciona a lista através do botão "Adicionar".

![image](https://github.com/user-attachments/assets/b326e3d0-4b09-4cae-801e-35cfd86f01d9)

Observações: Não é permitido inserir apenas um caractere e nem nomes repetidos:

![Screenshot 2025-02-12 184603](https://github.com/user-attachments/assets/e05ab227-2730-4d5e-a148-e68a7f8f2c46)

![Screenshot 2025-02-12 184711](https://github.com/user-attachments/assets/d6f7bee8-83a6-400c-978a-ecc1c5b339cc)


2. Após inseridos os nomes, basta clicar no botão "Sortear Amigo" que o sistema exibirá automaticamente o nome sorteado:
